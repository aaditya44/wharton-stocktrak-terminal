# StockTrak Research Terminal

Explainable research pipeline + client-mode trading research for the Wharton Global High School Investment Competition 2026-2027 (client: Laura Gao case study).

**Live site:** https://aaditya44.github.io/wharton-stocktrak-terminal/ (GitHub Pages from `main`, `index.html` at repo root)

## What this is

A single-file research terminal (`index.html`, no external assets) generated by `build_site.py` from cached daily bars and a dated evidence log:

- **Screener** - explainable cross-sectional ranking over a 68-symbol universe. Fixed a-priori factor weights (0.30 3m momentum / 0.15 1m momentum / 0.15 overnight Sharpe / 0.15 low-vol / 0.15 trend / 0.10 52w-high). No fitted parameters.
- **Client mode** - the Laura Gao mandate from the official case PDFs + the final 2026-09-19 due-diligence report: two-sleeve liability-driven architecture (growth + segregated reserve), reserve sized $430-440k at a conservative 3.0-3.5% discount, date-matched nominal ladder at 2033, reserve-coverage ratio and de-risk triggers first-class.
- **Backtests** - overnight vs intraday decomposition (H1-H5 pre-registered; train/validation + walk-forward discipline).
- **Experiment / Trade / Decision logs** - dated, auditable; every fill carries a confirmation ID and rationale (Trading Notes raw material).
- **Case study** - verified public-record diligence (with namesake warning), Monte Carlo v2 (fat tails + 2008 crash stress), reserve glidepath, co-sponsor range, official deliverable schedule, open items preserved.

## Pipeline

```
python3 build_site.py   # recomputes engine + client layers, rewrites index.html
```

- `engine.py` - factor computation + composite ranking -> `data/ranking.json`
- `client.py` - client suitability layer (vol bands, caps, profile) on top of the ranking
- `data/` - cached 1y daily bars per symbol (cache-on-success; history is never re-fetched, only the recent tail is refreshed)
- `ingest.py` / `browser_ingest.sh` - bar ingestion rails (Yahoo chart API; the logged-in browser path is the reliable one)

## Data + process policy

- Yahoo Finance daily bars via agent fetch paths; StockTrak account snapshots at scheduled checkpoints only (no aggressive scraping).
- Competition constraints encoded: $25 commission/trade, no shorts, no margin, no same-day exits; 200-trade allotment; practice resets 2026-09-25 16:00 ET, competition starts 2026-09-28 09:30 ET, trading ends 2026-11-06.
- Every fill is verified in transaction history before it enters the log; platform transaction-history values win over data-vendor approximations.
- Commit history is dated and append-only: each session's evidence lands as its own commit.
